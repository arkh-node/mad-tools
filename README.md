# madd_kit

```
[M·A·D]  model · agent · destruction
```

**maddteam toolkit для security-исследований ИИ и bug bounty.**

26 инструментов. Сейчас это конвейер на пути к единому фреймворку: mushahid видит, loom гоняет, notary запирает, arbiter судит, warden сторожит.

## Конвейер

- **mushahid** — مشاهد, тихий наблюдатель: CDP-логгер под всеми остальными
- **loom** — раннер пайплайнов: JSON-спека → исполнение MADD-компонентов
- **notary** — мутационный гейт батареи: нет подписи — нет мутации
- **arbiter** — LLM-оркестрированный триаж над общей базой находок
- **warden** — живой рантайм-монитор агентов: читает потоки событий, ловит аномалии
- **agent-reliability** — методология и тесты надёжности агентов
