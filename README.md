# mad-tools

Local CLI tools for MAD bug bounty workflows.

- `inkwell`: disclosure template generator
- `ferret`: finding organizer with JSON storage and a Textual board
- `banshee`: recon pipeline wrapper
- `periscope`: bug bounty scope snapshots and diffs
- `cloak`: identity-layer and OPSEC checker

Both tools are intended to run locally on `mrph`.
